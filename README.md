## Ажиллуулах

Долоо хоног бүр ижил зарчимтай — тухайн хавтас руу орж:

```bash
cd week3
npm install    # нэг л удаа
npm run dev    # http://localhost:5173
```

Тухайн долоо хоногийн дэлгэрэнгүй тайлбар, дасгалын жагсаалтыг
тэр хавтас доторх `README.md`-ээс үзнэ үү.

## Шаардлага

- Node.js 20.19+ эсвэл 22.12+ (Vite 8-ийн шаардлага)
- Хөтөч (Chrome / Edge / Firefox)
