# Week 3 — State ба үйл явдал (лаборатор)

`Сурагчийн_унших_материал.docx` (Web Programming II, 3 дугаар долоо хоног) хичээлийн
агуулгыг дагасан **7 жижиг дасгал** бүхий React лаборатор. React 19 + Vite.

Код бүр МОНГОЛ хэл дээр тайлбарласан: төлөв, hook, үйл явдал, форм, нөхцөлт дүрслэл
зэрэг бүх гол ойлголтыг мөр бүрд нь тайлбарлаж бичсэн.

---

## 1. Ажиллуулах

```bash
npm install     # шаардлагатай багцуудыг татаж суулгана (нэг л удаа)
npm run dev     # хөгжүүлэлтийн сервер асаана
```

Дараа нь хөтчөөр `http://localhost:5173` хаягийг нээнэ.

| Тушаал | Юу хийдэг |
| --- | --- |
| `npm run dev` | Хөгжүүлэлтийн сервер (хадгалахад автоматаар шинэчлэгдэнэ) |
| `npm run build` | Бүтээлтийн шалгалт — кодын алдаа байвал энд илэрнэ |
| `npm run preview` | Бүтээлтийн хувилбарыг локал серверээр турших |

## 5. Турших зүйлс (багшийн демо)

1. **1-р дасгал** — `+1`/`−1` дарах бүрд дэлгэц тэр даруй өөрчлөгдөнө. 0 дээр "Хасах"
   товч `disabled` болно.
2. **2-р дасгал** — "Устгах" дарахад зөвхөн тэр элемент явна; доод мөрөнд сүүлийн
   үйлдлийн мэдээлэл гарна. Хоосон үед өөр текст гарч ирнэ.
3. **3-р дасгал** — Хоосон нэр, `@`-гүй и-мэйлээр илгээж алдааны мөрүүдийг үзүүлнэ.
   Зөв бөглөөд илгээхэд амжилтын мэдэгдэл гарч, форм цэвэрлэгдэнэ.
4. **4-р дасгал** — "Нэвтрэх/Гарах" товч нэг төлвөөр 4 өөр газрыг зэрэг өөрчилнө.
5. **5-р дасгал** — Хайлт бичих, клуб сонгох, эрэмбэ солих үед хүснэгт шууд шинэчлэгдэнэ.
   Жагсаалтын төлөв тусад нь хадгалагдаагүйг тайлбарлана.
6. **6-р дасгал** — Аль ч хүүгийн товч дарахад эцгийн тоо өөрчлөгдөж, хоёр хүү хоёулаа
   шинэ утгыг харна.
7. **7-р дасгал** — Ажил нэмээд F5 дар: ажлууд `localStorage`-д үлдсэн.
8. **Эх код** — Дасгал солих бүрд доорх код мөн солигдоно. `Код нуух` дарж,
   `Код харуулах` дарж буцаана. `Хуулах` товч бүтэн файлыг clipboard-д хийнэ.
9. **Амьд засвар** — 2-р дасгал дээр `Засварлах` дарж, `Устгах` гэснийг `Хасах`
   болгож үз: 0.6 секундын дараа дээрх жагсаалтын товчны шошго өөрчлөгдөнө.
   Дараа нь санамсаргүй `}` нэмж улаан алдааны хайрцгийг үзүүлээд `Буцаах` дар.

## 6. Эх код: харах ба засварлаж ажиллуулах

### 6.1. Харах

Дасгал бүрийн **доор нь тэр дасгалын бүтэн эх код** харагдана — ингэснээр
"бичигдсэн код" ба "дэлгэцэн дээрх бодит үр дүн" хоёрыг зэрэг хараад, ямар код
ямар дүрслэл үүсгэж байгааг батлах боломжтой.

- **Мөр дугаартай** — хичээлийн тайлбар дахь "43-р мөр" гэх заалттай таарна.
- **Өнгөтэй** — тайлбар, текст, түлхүүр үг, JSX таг тус тусдаа өнгөтэй.
- **`Код нуух` / `Код харуулах`** — хайрцгийг хааж, зөвхөн үр дүнг үзэх боломж.
- **`Хуулах`** — засварлагч дахь одоогийн текстийг хуулж, өөрийн төсөлд туршина.

Хэрхэн ажилладаг вэ (`src/App.jsx`):

```js
const SOURCES = import.meta.glob('./labs/*.jsx', {
  query: '?raw',   // файлыг compile хийхгүй, энгийн ТЕКСТ болгож авна
  import: 'default',
  eager: true,     // ачаалах үед бүгдийг нэг дор уншина
})
```

`import.meta.glob` нь Vite-ийн боломж (стандарт JavaScript-д байхгүй): нэг бүлэг
файлыг нэг дор импортлоод, `?raw` ачаар эх текстийг нь буцаана. Сонгосон
дасгалын текст `CodeBlock` компонент руу `props`-оор очно.

### 6.2. Засварлах — засвар хийвэл дэлгэц (DOM) тэр дор нь өөрчлөгдөнө

Кодны толгойд байгаа **`Засварлах`** товчийг дарбал эх код нь текст засварлагч
болж нээгдэнэ. Тэнд бичсэн өөрчлөлт **0.6 секундын дараа автоматаар ажиллаж,
дээрх жишээ (демо) тэр засвараараа дүрслэгдэнэ** — "код → DOM" холбоог нүдээр
харж батлана.

| Товч | Юу хийдэг |
| --- | --- |
| `Засварлах` | Текст засварлагчийг нээнэ (`Код харах` гэж солигдоно) |
| `Буцаах` | Засварыг устгаж, эх код руу буцаана — демо ч эх хэлбэртээ орно |
| `Код нуух` | Хайрцгийг бүхэлд нь хаана |

Туршиж үзэх жишээ (1-р дасгал): `+1 Нэмэх` гэснийг `+5 Нэмэх` болгоод,
`setCount((prev) => prev + 1)`-ийг `prev + 5` болгоод үзээрэй. Дараа нь
`useState(0)`-ийг `useState(100)` болговол анхны утга хэрхэн өөрчлөгдөхийг хар.

Алдаа гарвал (таг хаагаагүй, эсвэл байхгүй утга дээр `.map` дуудсан гэх мэт)
дээрх хэсэгт **улаан хайрцагт** алдааны мессеж гарна. Хуудсыг дахин ачаалах
шаардлагагүй — кодоо засахад л дахин ажиллана.

Хэрхэн ажилладаг вэ:

1. `App.jsx` — `import.meta.glob(..., { query: '?raw' })`-оор бүх дасгалын эх текст.
2. `src/lib/compileLab.js` — Babel-ээр JSX-ийг энгийн JavaScript болгож,
   `new Function`-ээр ажиллуулаад `export default` компонентыг авна. Babel сан нь
   зөвхөн эхний засвар хийх үед л татагдана (динамик `import`, ~3MB).
3. `src/components/LivePreview.jsx` — Error Boundary: засварласан код дүрслэх үед
   алдаа гарвал хуудсыг бүхэлд нь унагахгүй, зөвхөн тэр хэсгийг алдааны мэдэгдэл
   болгоно (класс компонент — hook ашиглахгүй).
4. `src/components/CodeBlock.jsx` — `useEffect` + `setTimeout`-оор 0.6 секунд
   хүлээгээд (debounce) `onRun(newCode)` дуудна.

> Анхаар: `useEffect` нь 4-р долоо хоногийн сэдэв — зөвхөн энэ туслах компонентод
> ашиглагдаж байна. `labs/` доторх дасгалууд 3-р долоо хоногийн хүрээндээ
> (useState, үйл явдал, форм, нөхцөлт ба жагсаалтын дүрслэл) хэвээр байна.
>
> Мөн: ажиллах бүрд компонент ШИНЭЭР үүсдэг тул төлөв (state) эхнээс эхэлнэ — энэ
> нь React-ийн үндсэн зан төлөв: компонентын төрөл солигдвол хуучин төлөв
> хадгалагдахгүй.

## 7. Оюутнуудын түгээмэл алдаа (сануулга)

- Hook (`useState`)-ийг `if`, `for`, дотоод функц дотор дуудах — зөвхөн дээд түвшинд.
- `items.push(...)`, `items[0].done = true` гэх мэт **шууд өөрчлөлт** — React танихгүй.
  Оронд: `[...items]`, `items.filter(...)`, `items.map(...)`.
- `onClick={handleClick()}` гэж **хаалттай** бичих — дүрслэл бүрд ажиллана.
  Зөв: `onClick={handleClick}` эсвэл `onClick={() => handleClick(id)}`.
- Форм дээр `event.preventDefault()` мартах — хуудас дахин ачаална.
- `{items.length && <p>...</p>}` — хоосон үед дэлгэцэнд `0` гарна. Зөв: `items.length > 0 && ...`.
- `key`-д массивын индексийг хэрэглэх — элемент нэмэх/устгах/эрэмбэлэх үед алдаа гарна.
