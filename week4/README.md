# Week 4 — Компонентын амьдралын мөчлөг ба useEffect (Лаборатор)

"Сурагчийн унших материал" (4 дүгээр долоо хоног) дахь **дадлага даалгавруудыг**
бүрэн хамрах, нэг бүрэн ажилладаг Vite + React төсөл. Энэ төсөл нь бусдаас
хамааралгүй, дангаараа ажиллана.

## Хэрхэн ажиллуулах

```bash
cd week4
npm install     # зөвхөн эхний удаа (хамаарлуудыг татна)
npm run dev     # хөгжүүлэлтийн сервер: http://localhost:5173
```

Хөтчөөр `http://localhost:5173` хаягийг нээнэ. **F12 → Console** табыг нээж
ажиглах нь энэ лабораторын гол туршлага (эффектүүд console дээр бүртгэл үлдээнэ).

## Эх код: харах ба засварлаж ажиллуулах

Дасгал бүрийн **доор нь тэр дасгалын бүтэн эх код** харагдана (мөр дугаартай,
өнгөтэй). «Засварлах» товчоор кодыг **газар дээр нь засварлаж**, үр дүнг нь тэр
дор нь харна — засвар хийгээд **0.6 секундын дараа** дээрх жишээ (демо)
автоматаар тэр засвараараа ажиллаж эхэлнэ.

Засварлаж байх үед ч кодын **өнгө ба мөр дугаар хэвээр** харагдана: доод
давхаргад өнгөтэй код, дээр нь үсэг нь тунгалаг текст хайрцаг байрладаг
(курсор, сонголт, бичих ажиллагаа хэвийн). Мөн `!==`, `=>` зэрэг тэмдэгтүүд
фонтын лигатур болж нийлэхгүй — эх кодтой яг ижил харагдана.

| Товч | Юу хийдэг |
| --- | --- |
| `Засварлах` | Текст засварлагчийг нээнэ (`Код харах` гэж солигдоно) |
| `Буцаах` | Засварыг устгаж, эх код руу буцаана — демо ч эх хэлбэртээ орно |
| `Код нуух` | Хайрцгийг бүхэлд нь хаана |
| `Хуулах` | Засварлагч дахь одоогийн текстийг clipboard-д хуулна |

Туршиж үзэх жишээ:

1. **1-р дасгал** — `useEffect(() => { ... }, [])`-ийн хамаарлын массивыг арилгаж
   үз: эффект дүрслэл бүрд ажиллаж, console дээр бүртгэл нэмэгдэнэ.
2. **3-р дасгал** — `clearInterval` мөрийг устгаж, "нуух" товч дараад үз:
   цэвэрлэгээгүй үед таймер ажилласаар байгааг console-оос хар.
3. **5-р дасгал** — `fetch`-ийн `AbortController` мөрийг устгаж, хуудсыг дахин
   ачаалахгүйгээр дасгалыг сольж үз (хоцорсон хариуны асуудал).

Алдаа гарвал (таг хаагаагүй, эсвэл `undefined.map(...)` гэх мэт) дээрх хэсэгт
**улаан хайрцагт** алдааны мессеж гарна — хуудсыг дахин ачаалах шаардлагагүй,
кодоо засахад л дахин ажиллана.

Хэрхэн ажилладаг вэ:

1. `App.jsx` — `import.meta.glob(..., { query: '?raw' })`-оор бүх дасгалын эх текст.
2. `src/lib/compileLab.js` — Babel-ээр JSX-ийг энгийн JavaScript болгож,
   `new Function`-ээр ажиллуулаад `export default` компонентыг авна. Babel сан нь
   зөвхөн эхний засвар хийх үед л татагдана (динамик `import`, ~3MB).
3. `src/components/LivePreview.jsx` — Error Boundary: засварласан код дүрслэх үед
   алдаа гарвал хуудсыг бүхэлд нь унагахгүй (класс компонент — hook ашиглахгүй).
4. `src/components/CodeBlock.jsx` — `useEffect` + `setTimeout`-оор 0.6 секунд
   хүлээгээд (`debounce`) `onRun(newCode)` дуудна.

> Амьд засвар нь дасгалын кодыг ШИНЭЭР ажиллуулдаг тул эффектүүд дахин ажиллаж,
> console дээр шинэ мөрүүд гарна — энэ бол 4-р долоо хоногийн сэдэвтэй шууд
> холбоотой ажиглалт: компонент салж (unmount), дахин mount хийгдэж байна.

## Гол ойлголтууд (шалгах хуудас)

- [ ] **Гурван үе**: анхны дүрслэл (mount) → шинэчлэлт (update) → салгалт (unmount)
- [ ] **useEffect(функц, массив)** — 1-р арг: дүрслэл дууссаны дараа ажиллах ажил,
      2-р арг: хэзээ дахин ажиллахыг тодорхойлдог хамаарлын массив
- [ ] **Массивын 3 хэлбэр**: огт байхгүй (дүрслэл бүрд) / `[]` (ганц удаа) /
      `[утга]` (утга өөрчлөгдөх бүрд)
- [ ] **Цэвэрлэгээ (cleanup)**: эффектээс буцаасан функц — дахин ажиллахын өмнө
      ба салгах үед дуудагдана. Таймер `clearInterval`, сонсогч
      `removeEventListener` (нэмсэнтэй ижил заалт), хүсэлт `controller.abort()`
- [ ] **Гаж нөлөөг эффект дотор**: fetch, таймер, DOM/цонхны API-ууд дүрслэлийн
      үед биш, эффект дотор
- [ ] **3 төлөв**: өгөгдөл / ачаалал / алдаа — дүрслэлд тус бүрд нь харагдац
- [ ] **Хуучин утгад хүлэгдэхээс** сэргийлж функциональ шинэчлэл
      `setSeconds((prev) => prev + 1)`
- [ ] **Хөгжүүлэлтийн горимд эффект 2 удаа ажилладаг** — энэ нь StrictMode-ийн
      шалгалт бөгөөд бүтээлтэд давтагдахгүй (`src/main.jsx`-ийг үз)

## Гэрийн даалгавар (унших материалаас)

1. Хамаарлын массивтай эффектээр хөтчийн гарчгийг төлвөөс хамааруулан шинэчил
   (2-р дасгал энийг бүрэн харуулсан — өөрөө дахин бичиж үзээрэй).
2. Секунд тутам шинэчлэгдэх цаг харуулах компонент бичиж, цэвэрлэгээг зөв хий
   (3-р дасгалыг цаг болгон хувиргаж үзээрэй).
3. Цонхны хэмжээ ба гарын товчлуурыг сонсдог ХОЁР тусдаа эффект бичиж,
   сонсогчдыг салга (4-р дасгал дээр `keydown` сонсогч нэмээрэй).
4. Серверээс жагсаалт татах эффект бичиж, ачаалал ба алдааг нөхцөлт
   дүрслэлээр харуул (5-р дасгал).
5. Хоцорсон хариунаас сэргийлэх хоёр аргыг хэрэгжүүлж, ялгааг тайлбарла:
   (а) цэвэрлэгээнд тэмдэг тавьж хоцорсон хариуг алгасах,
   (б) AbortController-оор хүсэлтийг цуцлах (5-р дасгалд (б) бий).
