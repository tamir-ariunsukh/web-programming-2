# Week 4 — Компонентын амьдралын мөчлөг ба useEffect (Лаборатор)

"Сурагчийн унших материал" (4 дүгээр долоо хоног) дахь **дадлага даалгавруудыг**
бүрэн хамрах, нэг бүрэн ажилладаг Vite + React төсөл. Энэ төсөл нь бусдаас
хамааралгүй, дангаараа ажиллана.

## Хэрхэн ажиллуулах

```bash
cd week4
npm install     # зөвхөн эхний удаа (хамаарлуудыг татна)
npm run dev     # хөгжүүлэлтийн сервер: http://localhost:5173
```

Хөтчөөр `http://localhost:5173` хаягийг нээнэ. **F12 → Console** табыг нээж
ажиглах нь энэ лабораторын гол туршлага (эффектүүд console дээр бүртгэл үлдээнэ).

## Гол ойлголтууд (шалгах хуудас)

- [ ] **Гурван үе**: анхны дүрслэл (mount) → шинэчлэлт (update) → салгалт (unmount)
- [ ] **useEffect(функц, массив)** — 1-р арг: дүрслэл дууссаны дараа ажиллах ажил,
      2-р арг: хэзээ дахин ажиллахыг тодорхойлдог хамаарлын массив
- [ ] **Массивын 3 хэлбэр**: огт байхгүй (дүрслэл бүрд) / `[]` (ганц удаа) /
      `[утга]` (утга өөрчлөгдөх бүрд)
- [ ] **Цэвэрлэгээ (cleanup)**: эффектээс буцаасан функц — дахин ажиллахын өмнө
      ба салгах үед дуудагдана. Таймер `clearInterval`, сонсогч
      `removeEventListener` (нэмсэнтэй ижил заалт), хүсэлт `controller.abort()`
- [ ] **Гаж нөлөөг эффект дотор**: fetch, таймер, DOM/цонхны API-ууд дүрслэлийн
      үед биш, эффект дотор
- [ ] **3 төлөв**: өгөгдөл / ачаалал / алдаа — дүрслэлд тус бүрд нь харагдац
- [ ] **Хуучин утгад хүлэгдэхээс** сэргийлж функциональ шинэчлэл
      `setSeconds((prev) => prev + 1)`
- [ ] **Хөгжүүлэлтийн горимд эффект 2 удаа ажилладаг** — энэ нь StrictMode-ийн
      шалгалт бөгөөд бүтээлтэд давтагдахгүй (`src/main.jsx`-ийг үз)

## Гэрийн даалгавар (унших материалаас)

1. Хамаарлын массивтай эффектээр хөтчийн гарчгийг төлвөөс хамааруулан шинэчил
   (2-р дасгал энийг бүрэн харуулсан — өөрөө дахин бичиж үзээрэй).
2. Секунд тутам шинэчлэгдэх цаг харуулах компонент бичиж, цэвэрлэгээг зөв хий
   (3-р дасгалыг цаг болгон хувиргаж үзээрэй).
3. Цонхны хэмжээ ба гарын товчлуурыг сонсдог ХОЁР тусдаа эффект бичиж,
   сонсогчдыг салга (4-р дасгал дээр `keydown` сонсогч нэмээрэй).
4. Серверээс жагсаалт татах эффект бичиж, ачаалал ба алдааг нөхцөлт
   дүрслэлээр харуул (5-р дасгал).
5. Хоцорсон хариунаас сэргийлэх хоёр аргыг хэрэгжүүлж, ялгааг тайлбарла:
   (а) цэвэрлэгээнд тэмдэг тавьж хоцорсон хариуг алгасах,
   (б) AbortController-оор хүсэлтийг цуцлах (5-р дасгалд (б) бий).
